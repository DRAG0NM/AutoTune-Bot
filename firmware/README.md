# STM32接口说明

接口设计基于江协科技平衡车课程的09版“遥控器控制平衡车+数据回传”工程。课程源码和Keil工程未随仓库分发；本目录只保存[改造说明](PATCHES.md)。

设计内容包括115200串口、设备tick遥测、心跳看门狗、停机改参及命令处理。说明中的代码片段尚未在本项目完成编译、烧录和现场验收。当前说明缺少Stop/Start回执和实际参数读回，主机工具据此保持设备状态未知。

课程资料包的程序说明允许查看、使用和修改；取得原工程时仍应核对其附带许可。课程来源：[江协科技](https://jiangxiekeji.com)。本项目Apache-2.0许可不替代第三方材料许可。
