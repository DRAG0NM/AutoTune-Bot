# Agnes会话记录

JSONL保留规划文本、工具调用、返回结果和事件顺序。本机路径、用户标识、凭据字段、账号路由及上游请求追踪标识已替换为占位符；关联标识采用一致替换，保留对应关系。事件seq、effectId、toolCallId、runId和实验数值保留，缺失事件在审计结果中列出。

tool/result中的文档及代码正文是运行时读取内容的历史快照，可能包含已从当前文件移除的表述；现行用法以仓库当前文档为准。

早期及A/B/C/D会话附有历史审计摘要。D记录也包含此前C轮，D审计范围为seq658–1225。D2-T三批和M2两批另有对应导出。M2基线导出372个事件，覆盖4/4运行返回，但缺少1个effect结算及turn/end；条件积分导出57个事件，同样缺少1个effect结算及turn/end，未覆盖4条正式运行返回。两份M2导出均不完整；数值结果可以复算，但这些文件不能提供完整自主交互审计。

旧导出的通用手机号/身份证替换曾误伤数字和随机标识。现有事件已按id、seq、type从本机Agnes事件数据库只读匹配，恢复78处片段；没有新增或删除事件。事件时间、数值字段与effectId/toolUseId/runId及摘要字段均核对原记录。恢复位置和发布文件SHA256见[recovery-audit.json](recovery-audit.json)。私人归档保留旧导出及恢复副本。

运行 `npm run audit:sessions` 重新统计事件序列、effect及toolUseId调用/返回配对、非负整数时长和正式runId覆盖。不同导出可能包含多轮或中途范围，覆盖情况逐文件列出。

历史完整源码ZIP不在本目录；公开复现模块及原快照身份见[versions](../versions/README.md)。
