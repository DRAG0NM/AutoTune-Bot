# AutoTune-Bot：二阶倒立摆仿真PID AI调参助手

参考方向：工程仿真与优化；也涉及智能体与Harness工程。当前交付聚焦可复现的数值仿真，没有硬件运行要求。

## 问题与目标

PID整定需要在响应速度、超调、残差与控制输入之间权衡。仅凭单张曲线或一组低J参数，不能证明闭环调参有效；失败候选、试验条件和模型决策也需要留证。

本项目让AGNES作为“提出实验和解释反馈的调参助手”，以AGH为执行底座：接受目标与预算、规划候选、调用仿真、读取结构化指标、调整下一组参数、冻结已测可行最优、验证不同条件并交付CSV和图表。数值积分与PID运算由确定性Node.js工具执行，模型不代替控制周期计算。

## 实现

- 模型：非线性二阶单倒立摆，状态θ/ω；10ms控制步、50ms采样，固定种子可重现。不是双摆，也不是高保真实车数字孪生。
- 控制：继承既有离散PID约定，积分逐步求和、微分为测量差。参数不能直接解释为连续时间PID单位。
- 评价：先以摔倒和收敛门筛选，再比较超调、调节时间、稳态误差和控制平方积分代理组成的J；直接输出各加权贡献，减少模型量纲混淆。
- 约束：冻结计划、搜索工况、参数范围、轮数、评价配置和parent链。验证前拒绝非最优或不可行参数；失败记录保留。
- 输出：逐轮CSV、指标与诊断JSON、响应/控制/相轨迹SVG、HTML；批次汇总CSV、J与参数变化图。

AGH负责上下文、模型调用、工具执行审批、调用回执和会话记录。运行证据的平台模型为`agnes-3.0-flash`，primary/escalation/fast/compaction/verifier五个角色均为该模型；通过AGH中已配置的模型账户调用，Key不进入本项目。

| 顺序 | Kp/Ki/Kd | J | 收敛 |
|---|---|---:|---|
| 基线 | 5/0.1/5 | 0.7235 | 否 |

| AGNES反馈候选 | 4/0/12 | 0.1669 | 是 |

以上为真实AGNES会话中的四组执行参数；没有找到超过历史先验4/0/8的候选，不声称从零发现或全局最优。冻结4/0/8后，不同噪声种子、负初始角两项验证通过；10°/s冲击虽然在1050ms后恢复，但整轮末段均值误差0.1824°超过0.1°，未通过整轮收敛门。

373事件完整导出覆盖7/7正式runId，17次工具调用均有返回，34个effect意图均有结算。Codex在验收时逐项核准框架工具请求；候选选择与执行命令由AGNES提出。因此这是有工具审批的自主决策闭环，不声称无监督、无人工权限参与。

## 异常与局限

验收包含一次非交互CLI无法审批和一次框架TRANSPORT错误，随后在网页恢复。模型曾误判J主项、过度归因积分影响，并把实际6分35.289秒误报成4.5分钟。这些原记录未改写；当前工具补充分项，指令要求真实时间戳和假设措辞。离线测试验证工具改动，不能保证模型以后不再犯错。

仅为单套假设数值模型上的有限搜索，不保证其他对象、初始角、扰动或连续PID实现适用。轮数有工具限制，模型推理墙钟预算尚无硬截止器。两份较早D2-M2历史会话不完整，完整闭环主证据采用本次373事件导出。
