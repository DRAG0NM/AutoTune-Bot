# 官方提交项与本项目对应关系

核对来源：[官方规程第四章](https://agnes-ai.cn/hackathon#chapter-4)，2026-10-15读取。官网当前要求单ZIP≤200MB，按`组别-参赛编号-队伍名称-队长姓名.zip`命名；截止2026-10-15 12:00（北京时间）。以提交时官网为准。

| 必填项 | 对应材料与状态 |
|---|---|
| 基本信息 | docs/project-description.md，私人提交材料补充报名编号与成员信息 |
| 技术信息 | docs/project-description.md、docs/reproduce.md、docs/sources-and-ai.md及environment.json |
| 可运行作品／复现方式 | 根目录README、Node工具、完整源码、docs/reproduce.md；离线不需模型Key |
| 演示视频 | 由负责人另行录制3–5分钟，官网要求主视频链接，备用可选；不能仅用包内mp4替代链接 |
| 运行证据 | evidence/07_simulation-release-20261015，包括完整AGH导出、7轮CSV、冻结源码、配置、截图、校验工具与报告 |
| 正常／边界／失败样例 | selftest9例，docs/reproduce.md中另列三条可执行命令 |
| 成员声明 | 私人提交材料提供单人分工及AI辅助披露草稿，须负责人核实确认，不代签 |
| 公开内容 | ≥1条真实项目公开内容，需平台、有效链接、截图与发布日期；私有仓库不能直接作为公开证明，发布的演示视频可同时准备为该项材料 |

Git仓库同步、ZIP完整性通过不等于材料已全部提交。视频链接、公开内容证明及成员确认尚未补齐时，提交状态必须是待补材料。官网上传是单独的负责人操作，本项目工具不会代填身份或自动提交表单。

获奖后的代码公开要求与提交时的公开内容证据是两项要求。不要用“以后公开仓库”替代当前真实公开内容。
