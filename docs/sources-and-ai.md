# 来源、许可证与AI辅助开发披露

| 项目 | 来源及用途 |
|---|---|
| Agnes Harness | [AgnesAI-Labs/agnes-harness](https://github.com/AgnesAI-Labs/agnes-harness)，Apache-2.0，作为外部智能体底座；原验收基于指定提交并有effect计时补丁，补丁随证据提供，未分发作者带账户配置的运行目录 |
| Agnes模型 | `agnes-3.0-flash`，由AGH账户路由执行核心参数选择、反馈分析与工具调用；具体角色、调用顺序和模型标识见已脱敏会话 |
| 本项目代码 | 包含此前本项目的仿真、指标、压力配置与离散控制器，以及当前入口、报告和检查工具；当前工程许可证见根目录LICENSE（Apache-2.0） |
| 控制思路的历史来源 | 项目早期参考江协科技平衡车课程资料（https://jiangxiekeji.com）的控制结构开展实车开发。当前提交已移除固件、驱动和实车接口，不分发其完整课程固件；离散约定的历史沿革保留披露，不将历史来源冒充新发明 |
| 数据与图片 | 轨迹来自本项目确定性模拟器，testdata为合成示例；不是传感器实测。图表由本项目SVG代码生成；会话截图来自项目实际运行。不使用第三方外部实验数据、商业图片或赛事宣传图作为结果 |
| Node.js与系统工具 | Node.js、Git、PowerShell、WSL为外部执行环境，未将其运行时或node_modules打入作品源码包 |
| 开发期AI辅助 | 使用DSH及Codex进行代码生成、修改、排错、审查、测试设计、文档整理与打包。开发辅助不等于作品运行时参数决策，也不伪造为AGNES执行证据；提交负责人应核实理解、测试和披露这些贡献 |

真实AGNES验收时，Codex代操作者逐项核准框架工具请求并独立审核结果。参数候选和trial命令来自AGNES；固定demo、网格扫描、离线复核来自确定性工具，三者分别标明。

会话公开副本仅对本地绝对路径、账户路由和本机用户标识做精确替换，不用泛化手机号正则误改试验数字。原始导出保存在私人档案；公开manifest记录原始及公开散列、处理方法。事件次序、时间戳、runId/toolUseId/effectId、PID和指标保持不变。散列用于一致性核对，不等于数字签名或第三方认证。

成员真实信息、分工确认与独立完成声明属于私人提交材料，不放入对外仓库；不得代签或把未确认模板称作已签声明。当前披露不代替赛事工作组对独立完成要求的判断。
