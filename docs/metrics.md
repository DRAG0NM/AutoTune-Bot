# 指标与代价函数

实现位于 `bridge/lib/metrics.js`。单次评价要求 target 恒定，时间戳非负且严格递增，必要字段为有限数值。

| 字段 | 定义与单位 |
|---|---|
| `y0` | 首5%样本的角度均值，度 |
| `step` | target − y0，度 |
| `overshoot` | 回零用反向峰值/初始偏差；跟踪用正向峰值/阶跃幅值，无量纲比例 |
| `settlingMs` | 进入容差后直至记录结束都保持带内，且剩余观测至少300ms；从记录起点计，ms |
| `ssErr` | 末30%样本均值 − target，度 |
| `osc` | 首次穿越目标线后的穿越次数 |
| `energy` | 按相邻时间间隔、左端保持计算的输出平方积分，输出单位²·s；metrics 中取整 |
| `fail` | 数值/样本无效或角度越限等硬失败 |
| `converged` | 没有硬失败，调节时间有限，过冲≤0.3，abs(ssErr)≤tol |

容差 `tol = max(0.02 × abs(step), 0.1°)`，因此不是所有工况都使用0.1°。`settlingMs` 为有限窗口判据；窗口结束前不足300ms的带内段不计为调节完成。

默认代价为：

```text
J = 0.4 × min(overshoot / 0.5, 1)
  + 0.3 × min(settlingMs / 2000, 1)
  + 0.2 × min(abs(ssErr) / max(abs(step), 1), 1)
  + 0.1 × min(energy / 20000, 1)
```

权重由配置覆盖，结果中的 `jWeights`、`jNorm` 和 `evaluation` 记录实际口径。硬失败 J 序列化为字符串 `"Infinity"`，无定义字段为 null。有限 J 不必然收敛，候选筛选同时检查 fail 和 converged。

`diagnostics` 另外计算 IAE（°·s）、ISE（°²·s）、末窗 RMS、输出变化、观测饱和及施扰后恢复。全轮反向过冲不等于施扰后峰值；恢复从已知冲量时刻计算，要求进入容差并保持规定窗口。

仿真 out 是执行器前控制命令，派生轮速是代理值。输出平方积分不换算为电功率。10ms控制环统计与50ms遥测诊断采用不同采样粒度；稀疏遥测没有饱和点，不能排除控制步内饱和。
